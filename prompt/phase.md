HugaTiera development roadmap
1. Phase 1 — Requirements and system design
   
   Finalize the scope, user roles, use cases, workflows, folder structure, and database ERD.
   Start here
2. Phase 2 — Database and project setup
   
   Create the XAMPP project, MySQL database, connection file, reusable layout, and initial tables.
3. Phase 3 — Authentication and user roles
   
   Implement registration, login, logout, password hashing, sessions, and role-based access.
4. Phase 4 — Dashboards and profiles
   
   Build separate client, gardener, and administrator dashboards, plus profile management.
5. Phase 5 — Gardener services and portfolios
   
   Allow gardeners to create service listings, descriptions, categories, and portfolio galleries.
6. Phase 6 — Marketplace discovery
   
   Implement browsing, search, filtering, and viewing gardener profiles.
7. Phase 7 — Inquiry and quotation
   
   Let clients explain what they need and gardeners respond with details, availability, and indicative quotations.
8. Phase 8 — Messaging and notifications
   
   Add communication between clients and gardeners, along with relevant notifications.
9. Phase 9 — Booking and scheduling
   
   Add booking requests, acceptance or rejection, scheduling, and status tracking.
10. Phase 10 — Ratings and reviews
    
    Allow clients to review completed services.
11. Phase 11 — AI Garden Planning Assistant
    
    Integrate text-based AI using a suitable free-tier API, with backend protection and usage limits.
12. Phase 12 — Admin functions and reports
    
    Complete administrative management and basic reporting.
13. Phase 13 — Testing and deployment
    
    Test all roles, workflows, security, mobile responsiveness, and failure cases before deployment.
